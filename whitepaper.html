1. Overview

DesertCamel is an EVM-compatible blockchain built for high speed, reasonable transaction costs, and support for decentralized applications.

CML is the native cryptocurrency of the DesertCamel network.

CML is used as the base asset for transaction fees and as the native asset for network operations.

DesertCamel is designed to provide blockchain infrastructure for wallets, digital asset trading, DApps, and future blockchain services.

2. Vision

DesertCamel aims to build an accessible blockchain for users and developers, with CML as the central asset.

A modern blockchain must meet multiple requirements:

  • High transaction throughput.
  • Fast confirmation time.
  • Reasonable fees.
  • EVM tool compatibility.
  • Ecosystem scalability.
  • Transparent and verifiable infrastructure.
  • Simple user experience for mainstream users.

DesertCamel is developed with this direction.

3. What is CML?

CML is the native cryptocurrency of DesertCamel Blockchain.

CML can be used for:

New use cases may be added as the ecosystem evolves.

Each transaction on DesertCamel is processed through the EVM transaction mechanism.
